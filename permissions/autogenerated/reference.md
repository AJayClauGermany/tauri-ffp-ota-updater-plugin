## Default Permission

Allows checking for, downloading and installing frontend (OTA) updates

#### This default permission set includes the following:

- `allow-check`
- `allow-download`
- `allow-install`
- `allow-download-and-install`
- `allow-current-version`
- `allow-reset`
- `allow-notify-ready`
